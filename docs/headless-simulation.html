Headless match simulation

npm run simulate:match runs the built helper Auto-Bot against the official OpenFront engine in a random Team playlist match with the map defaults and Easy Nations. It emits periodic JSON progress records and a final result record.

npm run simulate:batch runs independent matches concurrently. The default worker and match count is the number reported by os.availableParallelism(), so every logical processor can execute one match. Set OFH_SIM_WORKERS or OFH_MATCHES to request a smaller measured batch when the workstation is shared with another workload. Each match has its own log under the temporary output directory shown at startup.

Match ticks remain authoritative and sequential inside each process. Parallelism is across independent games, which preserves engine ordering and determinism. The harness uses bound engine surfaces rather than a per-property Proxy so simulation-only adaptation does not dominate Auto-Bot decision time.
