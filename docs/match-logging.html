Per-match logging

Round Logger and Network Logger are enabled by default for new installations. The helper records WebSocket input and output, helper configuration messages, Auto-Bot status decisions and actions, runtime failures, network request metadata, match metadata, and significant game state changes. Existing installations keep their saved toggle choices.

Match data is never written to localStorage. Each completed match is retained only in memory for the current page session and exported as a separate newline-delimited JSON file named openfront-match-<timestamp>-<tick>.jsonl. The first line is file metadata; every following line is one ordered event with a timestamp and sequence number. A manual export remains available through exportRoundLog() in the page console.

Browsers can block automatic downloads or ask for permission. If that happens, allow multiple downloads for openfront.io or use the manual export function before leaving the page. Binary WebSocket payloads are represented by type and byte length; text packets are preserved verbatim.
